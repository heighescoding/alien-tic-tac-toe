# Alien Tic-Tac-Toe

A browser game with an orange and blue space theme, original cartoon alien characters, and a battle twist on tic-tac-toe.

## Workshop project

Created by Morgan Heighes on **October 19, 2026**, during the **All Things Open conference** workshop, **Vibe Coding for Non-Technical Professionals**. This project was built with AI assistance as a hands-on workshop exercise, from planning the game and its visual direction to creating a playable version and publishing the source on GitHub.

Workshop materials: https://github.com/mrhinkle/Vibe-Coding-for-Non-Technical-Professionals

## How to play

1. Press **Start game** and choose an empty square.
2. Battle Sunny, Nova, or Ziggy to decide who claims the square.
3. Counter the alien's attack: **Shield** blocks Laser, **Blast** beats Shield, and **Dodge** avoids Claw.
4. Win the battle to place an **X**. Lose and the alien places an **O** in that square.
5. Get three X marks in a row, column, or diagonal before the aliens get three O marks.

Each battle decides one square. The alien does not take an extra turn. Use **Play again** to start a new game after the result.

## Run locally

Download or clone this repository, then open `index.html` in a modern web browser.

No installation, build step, external assets, or API keys are required.

## Built with

- HTML for the page structure
- CSS for the responsive layout, orange and blue theme, and visual effects
- JavaScript for game state, battles, and win detection
- Inline SVG for the original alien characters

The complete game is contained in `index.html`.

## Project scope

This is a single-player workshop prototype. It runs entirely in the browser and does not require an account or backend.
